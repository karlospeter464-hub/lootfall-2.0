# Lootfall 2.0 — project instructions

Before changing gameplay, read the shared project rules at `C:/Users/elias/OneDrive/Dokumente/ChatGPT/Lootfall 2.0/AGENTS.md` and the relevant sections of `LOOTFALL_MASTERPLAN.md` in that same documentation folder. Those files are the maintained rules and design source for this separate game directory.

Code and game UI are English; development documentation is German. Do not infer feature authorization from the masterplan. Preserve wave-based card choices; proposed changes to progression, reward triggers or item persistence require explicit user confirmation. Current implementation: Echoes is awarded at run end for completed waves. INV1 adds eight run-only bag fields, scepter/book slots and four fixed items; picking up does not activate them. Bag/equipment reset on a new run; Hideout/spending and permanent items remain future work. F1 balancing has 33 settings and accepts legacy 28-setting profiles. Always use -- --test-mode for tests and scripted captures to isolate progress/profiles. See the game README for controls, application times and test commands.
